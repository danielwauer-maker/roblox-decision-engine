# R16 Real Pilot Go-Live

Status: IN PROGRESS

This sprint closes the remaining gap between the validated PlayDirective product and a real customer-ready founding-studio flow.

## Scope

1. Customer-facing founding-pilot application
2. Email enrollment and passwordless login
3. Dynamic Phase 2B onboarding progress
4. Phase 3 transactional lifecycle notifications
5. Phase 4 Stripe subscription plumbing and entitlement mapping
6. Real-world acceptance runbook from first visit to paid-conversion readiness

## Exit gate

R16 is complete only when a real external studio can:

- apply for the founding pilot from the public site
- receive confirmation by email
- be approved by an operator
- receive and redeem a private workspace invite
- later request a passwordless email login link
- connect a Roblox experience and sync live analytics
- follow a dynamic onboarding/progress state
- review priorities, evidence, analyst output, experiment guidance and weekly brief
- submit feedback
- see plan/billing state
- enter Stripe Checkout in test mode and return to the workspace
- open the Stripe Customer Portal in test mode after a subscription exists

Commercial activation remains opt-in. Stripe live mode must not be enabled until the manual test-mode checklist passes.
